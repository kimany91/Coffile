# Coffile

Application Windows pour préparer les montages vidéo : lien Google Drive → projet rangé (RUSHES, IMAGES, MONTAGE…), messagerie, exports, notes et AUTOEDIT.

Les versions sont publiées dans les **[Releases](../../releases)**. Coffile y cherche les mises à jour tout seul, au démarrage puis toutes les heures, et les installe automatiquement.

Pour installer : télécharge `Coffile-Setup-x.y.z.exe` dans la dernière release et lance-le.
